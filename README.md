# The Rectification

A responsive, single-page documentary and peaceful-action website.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish. The public URL will appear in this section.

## Features
- Responsive cinematic dark-green theme.
- Open letter / documentary section.
- Interactive common-ground slider.
- Evidence and trusted-resource links.
- Peaceful community action ideas.
- Action checklist stored locally in the visitor's browser.

## Privacy
This is a static site. It has no server, database, analytics, or public pledge counter. Checklist state is stored only in the visitor's browser using localStorage.
